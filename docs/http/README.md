除了前端接口，其他接口都必须按照 token 授权的方式，请按顺序浏览文档。

请先安装好服务器端，再阅读 `API文档` 进行调试。

# 部署说明

完整部署指南（服务器 → 后端 → 前端 → HTTPS）见 [部署指南](../deploy.md)。

后端一键部署详见仓库内 `install/README.md`，或直接：

```
cd install
./deploy.sh
```

会一键拉起 MySQL、Redis、phpMyAdmin、后端 API（`:8080`）与本接口文档站点（`:9889`）。超级管理员账号密码：`admin/admin`。
