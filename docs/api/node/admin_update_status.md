# /node/admin/update/status

隐藏或显示任意用户的节点，管理员接口。

节点隐藏后：该节点**及其子节点**下的文章不再出现在公开列表（首页、发现页、按标题搜索、
他人个人主页），只有节点作者本人仍能看到（列表项带 `node_hidden` 标记），文章直链仍可打开。
节点本身也不再出现在 `/u/nodes` 的公开节点列表里。

## 请求

需要管理员权限（路由带 Admin 标记，按用户组资源校验；超级管理员 `name=admin` 直通）。

```
POST /node/admin/update/status

{
	"id": 12,
	"status": 1
}
```

参数说明：

| 字段   |      含义   |类型  |   参数 |  必选 |
|----------|--------|------|------|------|
| id | 节点ID | int | 任意用户的节点 | 是 |
| status | 节点状态 | int | 0 正常；1 隐藏 | 是 |

## 响应

正常：

```
{
  "flag": true,
  "cid": "3b81485478b44b728a05e5449b0d26e0"
}
```

异常：

| 错误码 | 含义 |
| --- | --- |
| 101001 | 节点不存在 |
| 100006 | 无权限（非管理员） |
| 100010 | 参数错误 |
