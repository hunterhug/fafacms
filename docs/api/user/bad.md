# /user/bad

举报用户。只有登录的用户可以举报。不能举报自己、不能举报超管（admin）。

同一用户对同一被举报用户 **24 小时内只能举报一次**（重复举报返回 `110012`，不会取消之前的举报；24 小时后可再次举报，举报记录叠加，管理后台可见）。

## 请求

```
POST /user/bad

{
	"id": 10,
	"reason": "垃圾广告"
}
```

| 字段 | 含义 | 类型 | 必选 |
|------|------|------|------|
| id | 被举报用户 ID | int | 是 |
| reason | 举报原因（≤50，支持自定义） | string | 否 |

## 响应

举报正常：

```
{
  "flag": true,
  "cid": "2e5b753d299c4d54b6b3b44382c6e36b",
  "data": "+"
}
```

24 小时内重复举报：

```
{
  "flag": false,
  "error": {
    "id": 110012,
    "msg": "already reported in 24 hours"
  }
}
```

用户不存在：

```
{
  "flag": false,
  "error": {
    "id": 100003,
    "msg": "user not found"
  }
}
```
